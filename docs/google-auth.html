Connect Gmail

So the assistant can write to your Apple Notes

Why this is fiddly

Apple Notes stored on a Gmail account are ordinary Gmail messages under a label (normally Notes), each tagged with an Apple header. Writing one needs Gmail API access, and Google only hands that out to an OAuth client you own. Five minutes once, then it just works.

1. Make an OAuth client

  1. Open Google Cloud Console and create a project (any name).
  2. Under APIs & Services → Library, enable the Gmail API.
  3. Under OAuth consent screen, pick External, fill in the required fields, and add your own Gmail address as a Test user. Leaving the app in Testing mode is fine.
  4. Under Credentials → Create credentials → OAuth client ID, choose Web application.
